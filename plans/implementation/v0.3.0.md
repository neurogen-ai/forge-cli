# Implementation plan, v0.3.0

## Context

**What exists:** forge-cli through v0.2.0 works end to end on the `Neurogenesis/ngen-weave` Forgejo instance: nested-command registry (`internal/cli`), typed errors mapped to exit codes, staged diagnosis (`Diagnose` hook, filled by `wire` in `cmd/forge/main.go`), configurable protocol (`cmd/forge/protocol.go`), per-command help pages (`internal/cli/help.go`, every command's page starts with `use:`), and a save family writing append-suffixed JSON dumps (`internal/cmds/save.go`, `internal/store.Save`). Conversation reads go through `fetchConversation` in `internal/cmds/pr.go`; `api.GetReviews` and `api.GetReviewComments` are single-shot calls that truncate past the server page size; `Review`/`ReviewComment` carry no resolution or commit-anchor fields; nothing renders tables (a rendered conversation view is where the release wants human-facing defaults and global `--json`/`--table` overrides). This release implements `plans/releases/v0.3.0.md`: remote `resolved` state becomes the source of truth, views default to unresolved threads, downloads become explicit `pull` verbs writing into `.forge/cache/`, and seen/unseen local state is rejected (`plans/proposals/v0.3.0-oracle-counterpoint.md` carries the reasoning; `v0.3.0-extension.md` parks gh-parity extras for later releases).

**Files touched:** `internal/api/types.go`, `internal/api/pulls.go`, `internal/cli/cli.go`, `internal/cli/registry.go`, `internal/cli/help.go`, `internal/cmds/cmds.go`, `internal/cmds/pr.go`, `internal/cmds/pr_conv.go` (new), `internal/cmds/pr_review.go` (new), `internal/cmds/pr_resolve.go` (new), `internal/cmds/issues.go`, `internal/cmds/pull.go` (replaces `save.go`), `internal/cmds/views.go` (new, column specs and row builders), `internal/cmds/cache.go`, `internal/table/table.go` (new), `internal/store/store.go`, `internal/config/config.go`, `cmd/forge/main.go`, `scripts/probe-v0.3.0.sh` (new), `README.md`, `plans/releases/v0.3.0.md`.

**Depends on:** `plans/releases/v0.3.0.md` (the authority for behaviour; this plan resolves its §8 open questions inline), `plans/PRD.md` §5-§10 (precedence, exit codes, observability contract), `plans/implementation/v0.2.0.md` (the wiring shape this builds on). Supersessions noted where this plan closes release-doc questions: decisions D1-D3 near the bottom of this header.

**Precondition:** v0.2.0 is complete and on main. Cut every branch below from main after that point. Merging to main is out of scope for every branch in this plan and happens separately after review.

## Goals

1. Conversation reads and review rosters default to unresolved threads, driven entirely by server-side `resolved` state. `--all` and `--min-unresolved N` widen or narrow the filter.
2. Thread resolution is possible from the CLI: `pr comment resolve|unresolve <id>`, `pr resolve-all` with a safe dry-run default. Failures surface the server's own words; a server without resolve support fails loudly with a version hint rather than limping along.
3. The output contract holds everywhere: `--json`/`--table|-t` are parsed once globally, human views default to tables on a TTY and JSON in pipes, receipts stay JSON, and nothing reshapes stdout mid-pipe.
4. `save` dies; `pull` replaces it with overwrite-per-item dumps under `.forge/cache/`, receipts instead of payloads on stdout, and a flush that cannot eat `config.toml`.
5. `issue close` / `issue open` ride the PATCH endpoint. Small, but it finishes the object-state verbs the release named.

## Decisions closing the release doc's open questions

These are binding for every step below.

**D1. Where `resolved` comes from.** Servers vary: some carry a boolean, Gitea-derived list payloads signal resolution via a `resolver` user object. `ReviewComment.IsResolved()` (Step A1) normalises both. Nothing outside that function interprets raw fields again; if the live probe in Branch H finds a third shape, only `IsResolved` changes.

**D2. Which patch level carries `/resolve`.** The plan pins one candidate (`PATCH /repos/{o}/{r}/pulls/comments/{id}/resolve`, body `{"resolved": bool}`) as compile-time truth, exercised with an exact-bytes unit test. Branch H runs the probe script against the live instance and records the answer; if reality differs, the fix edits exactly the constant block from A3 and re-runs that test. No runtime feature-detection anywhere: the first failing request IS the probe, degraded loudly (Step D1).

**D3. Conv payload shape.** Only flat-with-kinds-ish shapes survive: `pr conv` speaks the new `ConvPayload`; the grouped-with-kind-tagged dump (`flatItem`, `groupedReview`) is retired, including from `pull` dumps (the nested dump switches to raw nested `api.ReviewComment`). No `--format` compat flag. Justification fits one line: `save` died with the readers that consumed the old shape, and the working-loop consumer of conv is agents reading unresolved-first data, not compatibility shims.

Other pinned conventions: conv keeps review-granular filtering and orders unresolved comments first inside every review it prints (bodies of settled nits stay readable, counts stay honest); `pull` receipts are unconditionally JSON and ignore both format flags; branch order below is mandatory where stated, advisory elsewhere.

```go
// ReviewComment models an inline review comment anchored to a diff hunk.
type ReviewComment struct {
	ID        int64      `json:"id"`
	User      User       `json:"user"`
	Body      string     `json:"body"`
	DiffHunk  string     `json:"diff_hunk"`
	Path      string     `json:"path"`
	CreatedAt *time.Time `json:"created_at"`

	// Anchors. TreePath repeats Path on some servers; both decoded, callers
	// prefer Path when non-empty.
	TreePath          string `json:"tree_path,omitempty"`
	Position          int64  `json:"position,omitempty"`
	OriginalPosition  int64  `json:"original_position,omitempty"`
	Line              int64  `json:"line,omitempty"`
	CommitID          string `json:"commit_id,omitempty"`
	OriginalCommitID  string `json:"original_commit_id,omitempty"`

	// ReviewID is the owning review. Servers encode this as
	// pull_request_review_id in list payloads.
	ReviewID int64 `json:"pull_request_review_id,omitempty"`

	// Resolution state. Resolved is present on newer servers; Resolver
	// appears whenever a human resolved the thread. See IsResolved.
	Resolved *bool `json:"resolved,omitempty"`
	Resolver *User `json:"resolver,omitempty"`
}

// IsResolved reports whether this comment's thread is resolved, folding the
// two encodings servers use into one predicate (decision D1).
func (rc ReviewComment) IsResolved() bool {
	if rc.Resolver != nil {
		return true
	}
	return rc.Resolved != nil && *rc.Resolved
}
```

Notes, non-negotiable: `ReviewID`'s tag changes from `review_id` to `pull_request_review_id` (the v0.1.0 tag matched nothing real; clients grouped by review keys externally ever since, so nothing regresses). Pointer `*bool`, not `bool`: absence must differ from false for future tooling. Value receiver on `IsResolved` keeps it callable on both `ReviewComment` and `[]ReviewComment` elements in range loops.

### Step A3: thread-resolution endpoints

`internal/api/pulls.go`, appended:

```go
// Thread-resolution encoding pinned by decision D2. The probe script at
// scripts/probe-v0.3.0.sh verifies this shape against a live instance; a
// mismatch means editing exactly this block plus TestThreadResolution.
const threadResolutionMethod = "PATCH"

// ResolveThread marks the review-comment thread rooted at commentID
// resolved. UnresolveThread clears it. Both target ROOT comment ids; reply
// ids yield server errors surfaced verbatim by callers. Re-resolving is
// idempotent server-side and stays safe to retry.
func (c *Client) ResolveThread(owner, repo string, commentID int64) error {
	return c.setThreadResolution(owner, repo, commentID, true)
}

func (c *Client) UnresolveThread(owner, repo string, commentID int64) error {
	return c.setThreadResolution(owner, repo, commentID, false)
}

func (c *Client) setThreadResolution(owner, repo string, commentID int64, resolved bool) error {
	path := fmt.Sprintf("/repos/%s/%s/pulls/comments/%d/resolve", owner, repo, commentID)
	body := struct {
		Resolved bool `json:"resolved"`
	}{resolved}
	return c.Do(threadResolutionMethod, path, nil, body, nil)
}
```

`Do` JSON-encodes non-nil bodies itself, so the wire bytes are exactly `{"resolved":true}` or `{"resolved":false}`; no raw-reader plumbing needed. Empty-body success responses decode into nothing since `out` is nil, which fits the 204-ish shape these endpoints return.

Exact-bytes test `TestThreadResolution` in `pulls_test.go`: httptest asserts `r.Method=="PATCH"`, `r.URL.Path=="/api/v1/repos/o/r/pulls/comments/88/resolve"`, and body matches `{"resolved":true}` (compare `string(io.ReadAll(...))`). Error path: respond 404 `{"message":"Not Found"}`, assert `err.(*APIError).Status==404` reaches the caller untouched (mapping lives in cmds, Step D1).

Do NOT:
- add fallback loops over alternate endpoints here or anywhere (decision D2),
- expose convenience "resolve review" batch calls,
- import `time` or jitter/retry logic; one shot per call.

```go
func DeclaresTable(c Command) bool {
	t, ok := c.(TableDefaulter)
```

Resolution helper, same file:

```go
// OutputIsJSON decides whether the command prints JSON instead of a table.
// Explicit flags win over every default; absent flags downgrade a table
// command to JSON whenever stdout is piped or redirected (unix convention),
// and leave JSON-only commands untouched.
func (c *Ctx) OutputIsJSON(w io.Writer, defaultIsTable bool) bool {
	if c.Format == FormatJSON {
		return true
	}
	if c.Format == FormatTable {
		return false
	}
	return !(defaultIsTable && isTerminal(w))
}

// isTerminal reports whether w is an interactive character device. Non-file
// writers (test buffers) are never terminals. stdlib-only: no x/sys dep.
func isTerminal(w io.Writer) bool {
	f, ok := w.(*os.File)
	if !ok {
		return false
	}
	st, err := f.Stat()
	if err != nil {
		return false
	}
	return st.Mode()&os.ModeCharDevice != 0
}
```

### Step B2: shared table renderers

New package `internal/table/table.go`. Grid-dumb on purpose: it knows nothing about PRs or issues.

```go
// Package table renders rows of cells as fixed-width text columns for
// human-facing command output. It owns layout only; column specs and cell
// formatting live beside the data they describe, in internal/cmds.
package table

import (
	"fmt"
	"io"
	"strings"
	"unicode/utf8"
)

// Column is one rendered column. Content exceeding Width truncates with a
// trailing ".." (always width-fitting).
type Column struct {
	Name  string // printed as-is in the header row; write headers already uppercased
	Width int    // display columns; 0 drops the column entirely
}

// Render writes a padded header row, one dashed separator line sized per
// column, then each row. Short rows pad with empty cells; extra cells drop.
func Render(w io.Writer, cols []Column, rows [][]string) error {
	if len(cols) == 0 || len(rows) == 0 {
		return nil
	}
	if err := writeRow(w, cols, headers(cols)); err != nil { return err }
	if err := writeRow(w, cols, seps(cols)); err != nil { return err }
	for _, r := range rows {
		if err := writeRow(w, cols, r); err != nil { return err }
	}
	return nil
}

func headers(cols []Column) []string {
	out := make([]string, len(cols))
	for i, c := range cols { out[i] = truncate(c.Name, c.Width) }
	return out
}

func seps(cols []Column) []string {
	out := make([]string, len(cols))
	for i := range cols { out[i] = strings.Repeat("-", cols[i].Width) }
	return out
}

func writeRow(w io.Writer, cols []Column, cells []string) error {
	parts := make([]string, len(cols))
	for i, c := range cols {
		cell := ""
		if i < len(cells) { cell = cells[i] }
		parts[i] = fmt.Sprintf("%-*s", c.Width, truncate(cell, c.Width))
	}
	_, err := fmt.Fprintln(w, strings.TrimRight(strings.Join(parts, " "), " "))
	return err
}

func truncate(s string, width int) string {
	r := utf8.RuneCountInString(s)
	if r <= width {
		return s
	}
	out, count := "", 0
	for _, rn := range s {
		w := utf8.RuneLen(rn)
		if count+w > width-2 { break }
		out += string(rn)
		count += w
	}
	return out + ".."
}
```

```go
// Write stores data as pretty-printed JSON at <dir>/<repo>-<number>.json,
// replacing any previous copy in place. Pulled dumps are current snapshots,
// one file per item; there are no timestamped variants. Returns the path.
func Write(dir, repo string, number int, data []byte) (string, error) {
	if err := os.MkdirAll(dir, 0o755); err != nil {
		return "", fmt.Errorf("store: create %s: %w", dir, err)
	}
	path := filepath.Join(dir, fmt.Sprintf("%s-%d.json", repo, number))
	if err := os.WriteFile(path, data, 0o644); err != nil {
		return "", fmt.Errorf("store: write %s: %w", path, err)
	}
	return path, nil
}

// WriteJSON marshals v with two-space indent then delegates to Write.
func WriteJSON(dir, repo string, number int, v any) (string, error) {
	data, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return "", fmt.Errorf("store: encode %s-%d: %w", repo, number, err)
	}
	return Write(dir, repo, number, data)
}
```

```go
type ResolveAllSummary struct {
	Requested int                 `json:"requested"`

	ID   int64  `json:"id"`
	Text string `json:"text"` // server message verbatim

	// o, r := ctx.GlobalFlags.Owner, ctx.GlobalFlags.Repo throughout this sketch

			}
		}
```

```bash
# Probes a live Forgejo instance for the three v0.3.0 unknowns from

echo "== idempotency check on winning candidate =="
```

## Abstraction notes

One line each on what future change each abstraction absorbs without scattering edits across callers.

- **IsResolved() predicate (A1)** absorbs the next server encoding discovery of "this thread got settled" in one function body; every consumer keeps calling it blind.
- **List[T]-based paginated fetchers (A2)** absorb server page-size drift transparently; future endpoints adopting this helper gain completeness for free.
- **Single-constant-block endpoint binding (A3)** absorbs the live-probe finding via a two-line edit plus its sibling unit test, nothing else.
- **Ctx.Format + OutputIsJSON (B1)** absorbs every new view surface (colour, markdown rendering, extra formats like diff text later in v0.4.x) through one resolution switch instead of per-command divergence.
- **TableDefaulter optional interface (B1)** absorbs adding more human-view commands without touching Run at all.
- **internal/table dumb grid (B2)** absorbs layout refinements centrally while column specs evolve beside their data, not inside a growing renderer.
- **fetchConversation shared gatherer (E2)** absorbs API-shape drift for conversation payloads so both conv views and pulls stay thin shells over one place that knows how to read reviews.
- **PullReceipt/PullCache separation (E2)** absorbs new counters (merged state, reviewer mentions) by extending the receipt struct while dump files stay stable for external consumers.
- **PRCache nested raw-api shape (E2)** deliberately exposes server objects directly, absorbing schema additions server-side without CLI-side rewrites of dump tooling.
- **buildConv pure-function core (C1)** absorbs new anchoring fields (line numbers vs commit refs evolving upstream) purely inside comparators.
- **mapResolveErr single gatekeeping point (D1/D2)** absorbs permission-model changes or stricter degradation rules across all four resolution verbs at once.
- **SetIssueState generic PATCH (F1)** absorbs future editable fields (title/body edits are planned v0.4.x extensions) by widening body maps, not signatures.
