# Implementation plan — v0.1.2

## Context

- **What exists:** forge-cli v0.1 works end to end. `prCreateCmd.Run` (`internal/cmds/pr.go`) resolves head/base then calls `api.CreatePullRequest`; any error goes through `mapErr` (`internal/cmds/cmds.go`), so a 404 from `POST /repos/{o}/{r}/pulls` prints the server's raw "The target couldn't be found." The wiring preflight already verified host/token/owner/repo, so this 404 means one of three things: missing base branch, missing head branch, or pull requests disabled on the repo. Behavior spec and rationale in `plans/releases/v0.1.2.md`; probe pattern to copy lives in `internal/api/repo.go` (`OwnerExists`).
- **Files touched:** `internal/api/branch.go` (new), `internal/api/branch_test.go` (new), `internal/cmds/pr.go`, `internal/cmds/pr_test.go`, `README.md`, `plans/releases/v0.1.2.md`.
- **Depends on:** `plans/releases/v0.1.2.md` (behavior authority). Do not restate its decisions here; reference them.

## Goals

1. A 404 from PR creation names the culprit: base branch, head branch, or disabled PR unit.
2. Zero extra requests when creation succeeds.
3. Every other status keeps today's exact error output.

# Branch A — api layer: BranchExists probe

### Step A1: add internal/api/branch.go

Create `internal/api/branch.go`:

```go
// BranchExists reports whether GET /repos/{o}/{r}/branches/{b} resolves.
// It returns false only for 404 (unknown branch); auth failures and other
// statuses are errors so a scope problem is never mistaken for a missing
// branch. Shape mirrors OwnerExists in repo.go.
func (c *Client) BranchExists(o, r, b string) (bool, error)
```

Implementation: send the branch as a query parameter on the collection path, `GET /repos/{o}/{r}/branches?branch={b}` with a `nil` output body. That is the form Gitea serves per-branch even when pulls are disabled, and it keeps branch names with slashes out of the URL path. On nil error return `(true, nil)`; if `errors.As` yields `*APIError` with `Status == 404` return `(false, nil)`; otherwise return `(false, err)`. Copy the structure of `OwnerExists` in `internal/api/repo.go`. Do NOT encode branch names into the URL path.

Do NOT:
- add list/delete/create branch helpers,
- touch `pulls.go`, `diagnose.go`, or the preflight.

Tests, create `internal/api/branch_test.go` (httptest against `NewClient(ts.URL, "tok", 0, nil)`):
1. Handler matches `r.URL.Path == "/api/v1/repos/o/r/branches"` with `r.URL.Query().Get("branch") == "main"` returning 200 `{}` → `(true, nil)`, and assert the query form was used.
2. Same path returning 404 with body `{"message":"The target couldn't be found."}` → `(false, nil)`.
3. Same path returning 403 → non-nil error wrapping `*APIError` with status 403.

Verify:

# Branch B — pr create 404 disambiguation

### Step B1: mapCreateErr in internal/cmds/pr.go

File: `internal/cmds/pr.go`. Also add the helper below to the same file (not a utils grab-bag; both are pr-create logic).

First add:

```go
// serverMessage quotes an APIError's body text, with a fallback when the
// server sent none.
func serverMessage(e *api.APIError) string {
	if e != nil && e.Message != "" {
		return e.Message
	}
	return "(no message in response body)"
}

// mapCreateErr converts a CreatePullRequest failure into a typed cli error,
// disambiguating 404s per releases/v0.1.2.md: base missing, head missing,
// or pull requests disabled. Any other status passes through mapErr
// unchanged.
func mapCreateErr(ctx *cli.Ctx, owner, repo, head, base string, err error) error {
	var apiErr *api.APIError
	if !errors.As(err, &apiErr) || apiErr.Status != http.StatusNotFound {
		return mapErr(err)
	}
	if ok, perr := ctx.API.BranchExists(owner, repo, base); perr == nil && !ok {
		return &cli.Error{
			Code: cli.ExitContext,
			Msg:  fmt.Sprintf("base branch %q not found in %s/%s", base, owner, repo),
			Hint: fmt.Sprintf("POST /repos/%s/%s/pulls returned 404; GET .../branches?branch=%s also 404'd; server said: %q. Check --base / FORGE_BASE / [defaults] base.", owner, repo, base, serverMessage(apiErr)),
		}
	}
	if ok, perr := ctx.API.BranchExists(owner, repo, head); perr == nil && !ok {
		return &cli.Error{
			Code: cli.ExitContext,
			Msg:  fmt.Sprintf("head branch %q not found in %s/%s", head, owner, repo),
			Hint: fmt.Sprintf("POST /repos/%s/%s/pulls returned 404; GET .../branches?branch=%s also 404'd; server said: %q. Check --head / FORGE_HEAD / your current git branch.", owner, repo, head, serverMessage(apiErr)),
		}
	}
	return &cli.Error{
		Code: cli.ExitContext,
		Msg:  fmt.Sprintf("repository %s/%s does not accept pull requests", owner, repo),
		Hint: fmt.Sprintf("branches verified but POST /repos/%s/%s/pulls returned 404; server said: %q. Pull requests are likely disabled for this repo (or it is a mirror); enable them in repo Settings, or check --repo.", owner, repo, serverMessage(apiErr)),
	}
}
```

Add `"errors"` and `"net/http"` to the file's imports. Then change exactly one line in `prCreateCmd.Run`:

```go
if err != nil {
    return mapCreateErr(ctx, ctx.GlobalFlags.Owner, ctx.GlobalFlags.Repo, head, base, err)
}
```

Behavior notes already decided in `releases/v0.1.2.md`: probe errors (`perr != nil`) fall through to the third case rather than masking the original 404; the server message appears in every hint unconditionally; no extra requests happen when `CreatePullRequest` succeeds because `mapCreateErr` only runs on error.

Do NOT:
- touch `mapErr` or any other command,
- pre-probe branches before the POST,
- gate the server message behind `ctx.Verbose`,
- change head/base resolution order.

Tests, extend `internal/cmds/pr_test.go` using the existing `testCtx(ts)` pattern (real `*api.Client` against httptest):

1. POST `/api/v1/repos/o/r/pulls` returns 404; both branch queries return 200 → Run returns `*cli.Error` code `ExitContext`, Msg contains `does not accept pull requests`.
2. POST 404; branch query for `base` returns 404 → Msg contains `base branch "main" not found`, hint contains the server text.
3. POST 404; base branch 200, head branch 404 → Msg contains `head branch`.
4. POST returns 500 → error text equals plain `500: ...` mapErr output, code `ExitRuntime`.
5. POST 200 → success JSON, and assert the handler saw no `/branches` request (zero probes on happy path).

For tests 2–3 route on `r.URL.Query().Get("branch")` in one handler.

Verify:

```
go test ./internal/cmds/ -run TestPRCreate && go build ./... && go test ./...
```

Expected: new cases pass, full suite green.
