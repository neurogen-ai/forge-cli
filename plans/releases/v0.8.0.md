# forge-cli — Release plan v0.8.0

Scope: auto-sync service. The CLI should be capable of starting / stopping / interrogating / configuring that service, but the actual service may be better as a dedicated .service file for systemd, with the CLI as a user-friendly front end to it. This note is the scope placeholder only: service implementation, config surface, and systemd integration design belong to this release's own implementation plan, which does not exist yet.

Depends on the v0.5.0 single-shot `forge pr sync-status` command existing first, so the service has a primitive to build on.

Renumbered from v0.6.0 (2026-08) to make room for v0.6.0 PR-lifecycle/CI-visibility and v0.7.0 release-engineering; scope unchanged.
