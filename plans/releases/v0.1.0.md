# forge-cli — Release plan v0.1

Scope: the minimum that replaces the `~/.bashrc` bash workflow end-to-end, plus the extension skeleton everything else hangs off.

## 1. v0.1 scope checklist

- [ ] `forge pr create` (title required; head/base default from config/remote; base defaults to repo default branch when derivable, else flag required)
- [ ] `forge pr get N`, `forge pr list [--state --limit]`
- [ ] `forge pr conversation N` — issue comments + reviews + per-review comments (replaces `forge-fetch-prc`)
- [ ] `forge issue create|list|get` (list: `--state --page --limit`)
- [ ] `forge save pr-conversation N` / `forge save issue N`
- [ ] `forge cache flush` (+ `--yes`, prints removed paths), `forge cache path`
- [ ] Auth via git credential fill with full override chain
- [ ] Repo context detection from `origin` remote (https / scp / ssh URL forms)
- [ ] Global + repo-local TOML config, merged
- [ ] `--verbose` request logging; structured stderr errors; documented exit codes
- [ ] Pagination via `page`/`limit` params + `Link` header parsing in api client
- [ ] README quickstart

## 3. Flag matrix

| command | flags |
|---|---|
| all | `--host --owner --repo --token --config --verbose --timeout` |
| `pr create` | `--title* --head --base --body` (*required unless defaulted) |
| `pr list` | `--state(open) --page(1) --limit(20)` |
| `pr conversation N` | `--format(flat\|grouped)` |
| `issue create` | `--title* --body --label(repeatable) --assignee(repeatable)` |
| `issue list` | `--state(open) --page(1) --limit(20)` |
| `save <type> N` | `--dir` (overrides configured savedir) |
| `cache flush` | `--yes` |

Positional `N` = PR/issue index. Missing required value after full default resolution ⇒ exit 2 naming the missing key.

## 4. Config examples

```toml
# ~/.config/forge/config.toml
[savedir]
pr-conversation = "~/forge-cache/prs"
issue           = "~/forge-cache/issues"

# <repo>/.forge/config.toml
[defaults]
base = "master"
[savedir]
pr-conversation = ".forge/prs"
issue           = ".forge/issues"
```

Merge rule: scalar per-key (maps merged key-wise), repo-local wins; `~` expanded;
relative savedirs resolve against repo root. `[defaults] base` participates in the
PRD §6 precedence chain (flag > env > local > global > server default branch).

## 5. Acceptance criteria & test plan

**Acceptance**
1. From a clone of a Forgejo repo: `forge pr create --title "test" --head feature/x && forge pr conversation <N>` reproduces both bash functions' behavior without any env vars set.
2. `forge pr conversation 42 | jq '.[0].body'` works (pure JSON stdout).
3. No disk writes from any non-`save` command (grep-level guarantee + test).
4. Bad token ⇒ exit 4, stderr contains server message verbatim.
5. Outside any repo with no flags ⇒ exit 3 listing missing values.
6. `cache flush` removes exactly the files it created.

**Tests (stdlib `testing` only)**
- `gitctx`: table tests for https/scp/ssh remote forms.
- `config`: merge precedence, savedir expansion.
- `auth`: chain order with fake credential helper (`GIT_ASKPASS`-style stub via PATH).
- `api`: httptest server asserting paths, headers (`Authorization: token …`), bodies, error decoding, pagination params.
- `store`: save naming/collision suffix; flush scope safety.
